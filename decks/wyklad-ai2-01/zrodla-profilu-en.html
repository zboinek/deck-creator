Step 5: user profile

How does the assistant know who the user is?

Four sources, one file. Every line in the profile has an origin.
1

Static profileat the start

The user types it in: “been cooking for a month, I have one hob”.

2

Long-term memorypast conversations

A week ago he mentioned he hates coriander. Today he won't get any.

3

Inference on the flycurrent window

He asks “what is a roux?”, so probably a beginner.

4

Feedback loopreaction

“That's too hard for me” corrects the profile for the future.

user_profile.md
# Kuba
- student, 19, lives in a dorm
- one induction hob, no oven
- budget: about 15 PLN per dinner
## Knowledge
- beginner, doesn't know techniques
- one new term per answer
## Preferences
- hates coriander
- likes Asian food
- prefers steps to descriptions
Sources 2 and 4 need someone (the app or the agent itself) to add a line to the file. Otherwise the knowledge dies with the conversation.
a profile is a file, not magic
