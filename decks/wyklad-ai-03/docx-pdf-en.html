What is really inside the file?

The same paragraph in two formats. DOCX remembers the structure, PDF only remembers where to put the letters.

DOCX is a ZIP archive of XML files

report.docx
├─ [Content_Types].xml
├─ docProps/core.xml      author, date
└─ word/
   ├─ document.xml        content
   ├─ styles.xml
   └─ media/chart.png
<w:pStyle w:val="Heading1"/>
<w:t>Third quarter results</w:t>
The heading knows it is a heading. Paragraphs, tables and metadata can be extracted directly.

PDF is instructions for drawing a page

BT
  /F1 18 Tf  72 720 Td
  (Third quar) Tj
  (ter res) Tj  (ults) Tj
  /F2 11 Tf  320 720 Td
  (Revenue grew) Tj
ET
Set the font, move the pen, draw the glyphs. There is no paragraph, heading or table. The extractor has to guess reading order, columns and tables from positions, and a scan is just an image that needs OCR.
Simplified PDF content stream: BT/ET is a text block, Tf the font, Td the position, Tj draw.
