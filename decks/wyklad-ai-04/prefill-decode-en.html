Reading is fast, writing is slow

One question to the assistant: 4000 input tokens, approx. 700 reasoning tokens, approx. 300 answer tokens.

prefill

0 s2 s4 s6 s 8 s10 s

Prefill reading the prompt

  • All 4000 tokens at once, in parallel
  • Bottleneck: GPU compute
  • Shorter thanks to the cache (step 7)

Decode writing the answer

  • One token per step, each depends on the previous one
  • Each step reads all the weights from GPU memory (L9)
  • Bottleneck: memory bandwidth, approx. 115 tok/s
For over 6 seconds the model writes for itself: the student sees a spinner. And every decode token occupies the GPU separately, which is why in step 6 an output token is much more expensive than an input token.
Illustrative times: gpt-oss on an H100, speed from the L9 measurements, one user.
