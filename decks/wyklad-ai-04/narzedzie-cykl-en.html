Step 7: tools

The model asks, the app executes

Ola asks: “Scale the béchamel to 40 portions”. The model does not calculate or run anything. It writes a request in JSON.
1
app → model
Messages as in step 6 plus tool descriptions: scale_portions(recipe_id, portions): “Scales a recipe's ingredients from the database to the given number of portions”
The model sees the description, never the function's code.
2
model → app
{"name": "scale_portions", "arguments": {"recipe_id": "bechamel", "portions": 40}}
Instead of an answer: a call request. JSON extraction from L10.
3
app executes
A plain Python function reads the recipe from the database and multiplies: {"butter_g": 500, "flour_g": 500, "milk_ml": 5000}
This is where the agency is: code can calculate, write, send, pay.
4
app → model
The result comes back as a new message with the tool role, appended to the list
Step 1: the result also has to go into the context.
5
model → Ola
“For 40 portions: 500 g butter, 500 g flour, 5 l milk. For gluten-free, swap the flour for cornstarch.”
Numbers from code, tone from the persona, substitute from the profile.
Simplified notation of the OpenAI-compatible API format. Tool and field names are ours.
