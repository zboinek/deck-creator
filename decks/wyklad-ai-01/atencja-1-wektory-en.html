How an LLM sees text

Every token is a vector of numbers

The model does not see letters. It sees a list of numbers that encodes the meaning of the token.
“bat” can be an animal or a baseball bat. At the start its vector is the same in every sentence: both meanings live in it at once. The next slides show how attention settles it.
Simplification: word ≈ token. In a real model the vector has several thousand numbers, not five.
1 token = 1 vector
