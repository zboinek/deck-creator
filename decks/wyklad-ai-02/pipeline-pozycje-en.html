Pipeline

From the prompt to the transformer input

The embedding alone does not know where a word stands, so the position is added to the vector.

User prompt

Have you seen my bat?

The text exactly as the user typed it.

→

Tokenization

Haveyouseenmybat?

The text turns into token numbers.

→

Embedding

bat
0.72
-0.19
-0.71
…

Every token gets a vector of fixed length.

→

+ position

bat, position 5
vector + information on where the token stands in the context

Only this goes into the transformer.
