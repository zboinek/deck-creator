Why fewer bits

One model, four different sizes

It is simple multiplication: number of parameters × how much space one takes. Example: 70 billion parameters.
NVIDIA H100 card: 80 GB
FP324 bytes per parameter
280 GB
FP162 bytes per parameter
140 GB
does not fit
Q81 byte per parameter
70 GB
fits, but little is left for context
Q4half a byte per parameter
35 GB
fits, with room to spare
Like a photo saved as a smaller file: the details get worse, but you can still see the picture. Every bit we save costs a little quality, as we saw in the previous lecture.
